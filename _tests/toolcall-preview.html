Ask an AI agent to change something, then try to undo it

One plain-English request, run ten times by the same AI agent, wired up three ways. Left to write its own code, it gets the job done, but differently every time and with no record of what it touched. Told to keep a log, it usually does. Connected to pre-written tools, every change is recorded by the tool itself, along with exactly how to reverse it. A scripted replay of illustrative runs, not a live model.

The replay loops through all ten runs. It starts paused on the last run if your system asks for reduced motion.
